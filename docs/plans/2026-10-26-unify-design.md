# Unify 智能辅助审核后台 — 设计方案

日期：2026-10-26  
状态：已确认（待实现）

## 1. 目标与边界

新建独立后台 `apps/unify`（`@ctp/unify`），与 portal/ops/dci 等无业务耦合。

- **技术**：Vite + React + React Router，本地 mock store（与 ops 同形态）
- **登录**：自建登录页，本地用户名/密码；**本期不接 SSO**（预留后续作为 SSO 子系统接入）
- **端口**：`3010`

## 2. 信息架构

| 路径 | 页面 |
|------|------|
| `/login` | 登录（用户名 + 密码） |
| `/` | 首页（纯欢迎） |
| `/audit/tasks` | 智能辅助审核任务列表 |
| `/lists/user-blacklist` | 用户黑名单管理 |
| `/lists/ip-whitelist` | IP 白名单管理 |

侧栏分组：

1. 首页

布局：顶栏 + 侧栏 + 内容区；品牌名 **Unify**；复用 `@ctp/styles`。

## 3. 智能辅助审核任务列表

### 3.1 筛选项（对齐产品截图）

两行四列：

1. DCI申领记录ID、作品名称、作品类型、申领类型
2. 著作权人ID、DCI申领平台、提交时间（起止）、状态

查询 / 重置。

### 3.2 列表列

DCI申领记录ID｜作品名称｜作品类型｜申领类型｜著作权人｜登记提交时间｜DCI申领平台｜渠道名｜最后更新时间｜**风险灯**｜**内容安全等级**｜状态｜操作

### 3.3 三项审核

| 审核项 | 结果 |
|--------|------|
| 内容安全审核 | pass / fail；fail 时附带 riskLevel |
| 作品登记查重 | pass / fail |
| 疑似侵权审核 | pass / fail |

**内容安全风险等级（仅文字敏感词，不做图/视频识人事物）**

- 命中高危敏感词 → 高危
- 未命中高危、命中中危 → 中危
- 其余不通过 → 低危
- 通过 → 无等级（显示 —）

词库来源：名单管理「敏感词库」中启用中的词条。

### 3.4 红黄绿

| 灯 | 条件 |
|----|------|
| 红 | 内容安全审核不通过 |
| 黄 | 内容安全通过，但查重或侵权任一项不通过 |
| 绿 | 三项均通过 |

红优先于黄。

### 3.5 操作与人工复核

- **查看**：详情（抽屉或页），完整提交材料 + 三项审核明细 + 敏感词命中
- **人工复核**（存在任一项不通过时）：同材料视图；可「人工审核通过」→ 记复核日志，重算灯色（通常变绿）
- **提交材料**：查看/补传人工审核材料包（mock）
- **撤销**：按状态条件展示，mock 提示即可

## 4. 名单管理

### 4.1 用户黑名单

- 维度：用户 ID / 账号 / 设备 ID
- 字段：类型、匹配值、生效时间、失效时间、备注、启用/停用、创建人/时间
- 能力：CRUD、启用停用、批量导入导出（CSV）、命中日志
- 过期：不在 [生效, 失效] 内视为无效，列表可标「已过期」

### 4.2 IP 白名单

- 类型：单 IP / IP 段（起-止）/ CIDR
- 字段：类型、表达式、备注、状态、创建时间、命中次数
- 能力：CRUD、批量导入导出、命中统计与近期明细
- 与黑名单并存时：**黑名单优先**（注释说明，本期不做实时网关）

### 4.3 敏感词库（黑名单类）

- 字段：词条、危级（高/中/低）、启用/停用、备注、更新时间
- 能力：CRUD、按词/危级筛选、批量导入导出
- 与审核联动：内容安全判定读启用词库；改词库不回溯已审任务

## 5. 实现顺序（建议）

1. 脚手架：`apps/unify`、登录、布局、欢迎首页、根脚本 `dev:unify` / `build:unify`
2. 敏感词库 store + 页面（审核判定依赖）
3. 审核任务列表 + 详情/人工复核
4. 用户黑名单、IP 白名单

## 6. 明确不做（本期）

- SSO 接入
- 图片/视频敏感内容识别
- 真实网关拦截与实时名单同步
- 改词库后批量重算历史任务

# DCI® 技术服务中心 — 按代码实现梳理的需求说明

> **文档性质**：以当前仓库三端实际代码为准的「已实现 / 已占位」需求基线。  
> **对照原文**：`docs/documents/技术服务中心细化.md`  
> **对齐原则**：原文与代码冲突时，**以代码为准**；原文有、代码无的能力记为「未实现」；代码有、原文无的能力记为「代码新增」。  
> **工程边界**：三端均为前端原型；业务数据多为内存 Mock，**无真实后端 API / 持久化 / 跨端会话打通**。  
> **梳理日期**：2026-08-20  
> **代码范围**：
> - 对外门户 `apps/portal`（Next.js，端口 3000）
> - 企业控制台 `apps/customer`（Vite React，端口 3002）
> - 运营后台 `apps/ops`（Vite React，端口 3001）

## 4. 接口约定（以运营后台目录为准）

原文路径如 `/api/v1/verify/dci` **不被代码采用**。当前文档化路径：

| 查重 | `POST /v1/audit/duplicate/single` | `.../batch` |

通用：请求头 `X-Api-Key`；响应 `code/message/data/requestId`；可选 `callbackUrl`。

| 5 | 智能审核形态 | 疑问是否拆 3 产品 | 侧栏合并 1 入口且占位 |
| 6 | API 路径 | `/api/v1/...` | `/v1/{verify\|audit}/{code}/{single\|batch}` |
| 7 | 核验报告 | PDF | Toast / CSV 演示 |
| 8 | 内容管理 | 目录页+文章页分离 | 合并为 `/content/hc` |
| 9 | 运营登录与 RBAC | 完整会话与按钮权限 | 无登录；权限树可配，几乎不生效 |
| 10 | 帮助中心联动 | 前后台一致 | 门户静态；运营独立内存 |
| 11 | ICP / 空闲退出等 | 有讨论 | 未实现 |
| 12 | 控制台鉴权 | 已开通企业 | 无鉴权 |

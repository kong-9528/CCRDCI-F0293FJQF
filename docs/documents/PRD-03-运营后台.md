## 相关平台与依赖

| 依赖项 | 说明 |
|--------|------|
| 使用者 | **内部运营人员**（运营账号；与企业账号体系隔离） |
| 上游 / 协同 | 客户平台提交的开通申请；统一后端履约流水与账本（总章闭环一、二） |
| 下游 / 联动 | 审核通过与额度配置驱动客户平台解锁与计费；门户/帮助/FAQ 内容发布驱动门户展示（闭环三） |
| 本平台职责 | 开通审核、客户与合同、产品服务与额度、产品上下架、运营统计、门户与帮助内容、角色用户与操作审计、开放接口目录 |
| 不在本平台 | 门户营销浏览与企业登录；客户侧 WebUI 调用与企业自建 API Key |

关键闭环（简述）：客户提交开通申请 → 运营审核并配置产品/额度 → 客户可用 → 运营调账/停用/续约 → 统计对账；同时运营维护门户与帮助内容对外生效。

**访问门禁（全局）**：

| 状态 | 行为 |
|------|------|
| 未登录 | 仅可访问运营登录页；访问业务路由应引导至登录 |
| 已登录且账号启用 | 按角色权限可见菜单与操作；无权限页展示无权限空态或拒绝 |
| 已登录但账号停用 / 会话失效 | 不可继续业务操作；需重新登录或联系管理员 |

根路径 `/`：已登录 → `/dashboard`；未登录 → 运营登录入口。

### 可售产品与客户侧对照（全站约定）

运营侧**配置与计费**以可售产品 code 为准；客户平台 WebUI 可拆分子页，但额度归属同一打包 code。

| 品类 | 运营可售 code | 名称 | 客户平台 WebUI |
|------|---------------|------|----------------|
| 版权核验 | `dci` | DCI核验 | `/verify/dci` |
| 版权核验 | `info` | 版权登记信息核验 | `/verify/info` |
| 版权核验 | `certificate` | 版权登记证书核验 | `/verify/certificate` |
| 智能辅助审核 | `workReview` | 作品智能辅助审核 | 内容安全 / 查重 / 侵权三页共用额度；能力级上下架见产品管理 |

历史子 code（`safety` / `duplicate` / `infringement`）在配置与筛选中归一为 `workReview`；能力上下架单独管理。

额度类型：`unlimited`（不限量）/ `total`（有效期内总量）。合同服务期用于提醒与展示，**不**单独控制登录；账号能否登录取决于账号启用/停用。调用能否成功取决于产品开通、未停用、未过期与剩余额度（总章闭环二）。

## 全局：布局壳层与公共交互

> **C1 状态**：本章已按元素级补全。  
> **适用范围**：运营后台全部已登录业务页（登录页不使用本壳层）。  
> **布局**：左侧栏 + 右侧（顶栏 + 内容区）。

### 业务故事 / 目标

为运营人员提供统一工作区：侧栏按业务域导航，顶栏展示当前位置与当前用户；菜单与页内按钮受角色权限控制；退出须二次确认。

### 会话与展示名

| 需求点 | 说明 |
|--------|------|
| 运营会话 | 由统一身份服务签发**运营用户 JWT**；与门户/客户平台企业会话隔离，不可混用。 |
| 未登录访问业务路由 | 跳转运营登录页 `/login`，可携带 `redirect`（原路径）供登录成功后回跳；无合法 redirect 则进 `/dashboard`。 |
| 会话失效 / 账号中途停用 | 清除本地运营会话；跳转 `/login`；可选 Toast「登录已失效，请重新登录」。 |
| 展示名 | 取当前用户「用户名称」（`displayName`）；缺省回退登录名。 |
| 头像字 | 取展示名去空白后首字；空则「运」。 |

### 权限判定通则

|--------|------|

## 运营登录页

> **C1 状态**：本章已按元素级补全。  
> **路径**：`/login`  
> **壳层**：独立全页，**不**使用侧栏/业务顶栏。  
> **说明**：与门户企业登录隔离（总章闭环四）；校验运营账号；独立静态 `login.html` 不在本系列范围。

### 业务故事 / 目标

运营人员使用运营账号登录后台；校验与鉴权失败有固定提示；成功进入首页或原目标页。

### 板块：登录表单（Form）

#### 交互总则

| 需求点 | 说明 |
|--------|------|
| 进入条件 | 未登录访问本页；已登录访问本页 → 重定向 `/dashboard`（若带合法 `redirect` 则优先进 redirect）。 |
| 鉴权目标 | 调用统一身份服务校验**运营账号**；成功写入运营会话。 |
| 禁止 | 不展示任何演示用密码明文；不提供门户「忘记密码」入口（运营找回走线下/管理员重置，本页不做自助找回）。 |

#### 元素说明

| 元素 | 需求说明 |
|------|----------|
| 页标题 | 「运营后台登录」 |
| 辅助说明 | 「请使用运营账号登录。企业账号无法登录本系统。」 |
| 登录名 | 字段名「登录名」。单行文本。必填。默认空。placeholder「请输入登录名」。任意可见字符；提交前 trim。自动完成：username。 |
| 密码 | 字段名「密码」。单行密码框（密文）。必填。默认空；进入本页或提交失败后可保留登录名、清空密码。placeholder「请输入密码」。自动完成：current-password。 |
| 错误提示 | 展示在表单内、提交按钮上方。成功时不展示。 |
| 登录按钮 | 主按钮。默认文案「登录」；请求中文案「登录中…」且按钮禁用，防止重复提交。 |

#### 校验与结果

| 时机 / 条件 | 提示原文或行为 |
|-------------|----------------|
| 点击登录：登录名 trim 后为空，或密码为空 | 「请输入登录名和密码」；不发起请求 |
| 账号不存在或密码错误 | 「登录名或密码错误」 |
| 账号状态为停用 | 「账号已停用，请联系管理员」 |
| 其它服务端错误 | 展示后端可读文案；若无则「登录失败，请稍后重试」 |
| 成功 | 写入运营会话；跳转：若 URL 查询参数 `redirect` 为本站相对路径且非 `/login` → 该路径；否则 → `/dashboard` |

## 首页（运营看板）

> **C1 状态**：本章已按元素级补全。  
> **路径**：`/dashboard`（根路径 `/` 已登录时重定向至此）

## 产品 / 能力上架管理

> **C1 状态**：本章（版权核验页 + 智能辅助审核页）已按元素级补全。  
> **路径**：`/products/verify`、`/products/audit`；`/products` → `/products/verify`。  
> **页权限**：列表可见 `products.list` 或 `products`；切换上下架另需 `products.settings` 或 `products`（无 settings 时开关只读或隐藏，见下）。

### 业务故事 / 目标

控制可售产品及智能审核子能力的上架状态，影响门户可展示性、新开通可选范围，以及履约层对 WebUI/API 的拒绝（总章闭环二）。本版**仅**提供上下架开关，不提供新建自定义产品页。

### 业务影响（上下架通则）

| 状态 | 含义 | 对客户 / 门户 / 履约 |
|------|------|----------------------|
| 上线 / 上架（online） | 对外可用 | 可新开通；已开通且额度有效时可调用；门户可展示对应能力 |
| 下线 / 下架（offline） | 对外停用 | 不可新开通该产品/能力；已开通客户调用时履约拒绝（不计成功次）；门户对应入口可隐藏或展示不可用（细则见门户 PRD） |

智能审核：打包产品下架 → 三个子能力均不可用；单能力下架 → 仅该能力 WebUI/API 不可用，其它能力不受影响（打包产品仍为上架时）。

文案约定：版权核验页使用「上线 / 下线」；智能审核页使用「上架 / 下架」。确认弹窗与开关旁标签用语保持一致。

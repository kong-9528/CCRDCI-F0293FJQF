## 相关平台与依赖

| 依赖项 | 说明 |
|--------|------|
| 使用者 | 未登录访客；已登录企业用户 |
| 上游配置 | 运营后台维护的门户内容、接入指南文章、FAQ、联系信息（见总章「闭环三」） |
| 下游跳转 | 登录成功后可进入 **客户平台**；产品开通与调用在客户平台完成（见总章「闭环一、二、四」） |
| 本平台职责 | 品牌与产品介绍、接入说明、FAQ、企业登录入口、对外联系信息；**不承载**产品调用与额度管理 |

关键闭环（简述）：访客在门户了解产品 → 线下/联系合作 → 企业账号登录 → 进入客户平台使用；门户展示内容由运营配置后生效。

## 全局：站点壳层与公共交互

> **C1 状态**：本章已按元素级补全。

### 业务故事 / 目标

门户所有业务页共享同一套顶栏与页脚，保证品牌一致、导航可达、登录态可感知。企业用户可在门户完成登录并跳转客户平台；未开通合作的访客可通过「加入合作」获取联系方式。登录与合作弹层在多页复用，避免各页重复实现。

### 板块：登录弹窗

#### 交互总则

| 需求点 | 说明 |
|--------|------|
| 打开入口 | 顶栏「登录」按钮；其它页若提供登录入口，同样打开本弹窗。 |
| 关闭方式 | 点击遮罩、点击右上角关闭、按 Esc。关闭时解锁页面滚动。 |
| 打开时重置 | 清空密码框与错误提示；用户名可保留上次输入（目标：打开时清空密码，用户名可不清）。禁止背景滚动。 |
| 鉴权目标 | 调用统一身份服务校验企业账号；成功则写入门户登录态并关闭弹窗；失败展示错误文案。 |

#### 表单元素（Form）

| 元素 | 需求说明 |
|------|----------|
| 弹窗标题 | 文案「登录」。 |
| 辅助说明 | 文案提示使用企业账号登录。不展示任何演示用密码明文（正式环境）。 |
| 用户名 | 字段名「用户名」。单行文本。必填。默认空。placeholder「请输入用户名」。任意可见字符；提交前 trim。自动完成属性：username。 |
| 密码 | 字段名「密码」。单行密码框（密文）。必填。默认空；每次打开弹窗清空。placeholder「请输入密码」。自动完成属性：current-password。 |
| 错误提示 | 提交失败时展示在表单内。文案示例：「请输入用户名和密码」「用户名或密码错误」；其它后端错误原样或映射为可读文案。成功时不展示。 |
| 忘记密码 | 文字链「忘记密码？」。点击关闭登录弹窗并跳转 `/forgot-password`。 |
| 登录按钮 | 主按钮，通栏。文案默认「登录」；请求中文案「登录中…」且按钮禁用，防止重复提交。 |
| 提交校验（前端） | 用户名 trim 后为空或密码为空 → 不发起或返回「请输入用户名和密码」。 |
| 提交校验（后端） | 账号不存在、密码错误、账号停用、未开通等 → 统一或分类错误提示；成功返回企业用户标识与展示名。 |
| 成功后行为 | 关闭弹窗；顶栏切换为已登录；展示名默认取账号名（若档案有姓名/昵称则优先生效）。 |

## 首页

> **C1 状态**：本章已按元素级补全。  
> **路径**：`/`  
> **锚点**：版权核验分区 `#verify`；智能辅助审核分区 `#audit`（与全局顶栏 hash 滚动约定一致）。

### 业务故事 / 目标

让访客在首屏理解平台价值主张，并快速看到「版权核验」「智能辅助审核」两大品类及下属六项产品，建立信任；通过顶栏进入专题页、接入指南或登录，完成进一步了解与转化。首页以展示与导流为主，不承载产品调用。

### 内容来源

| 需求点 | 说明 |
|--------|------|
| 数据来源 | 首屏文案、产品分区标题/导语/产品卡片文案，由运营后台「门户内容」配置并发布后生效；未配置时使用平台默认文案包 |
| 数据范围 | 对全部访客可见（无需登录） |
| 文案策略 | PRD 只约定字段结构与交互；具体营销长文以运营配置为准，此处不整篇收录 |

### 板块：首屏焦点轮播（Hero）

#### 交互总则

| 需求点 | 说明 |
|--------|------|
| 帧数量 | 固定 3 帧（平台能力 / 版权核验 / 智能审核），顺序可配置 |
| 自动播放 | 默认开启；间隔 **6 秒** 切换至下一帧；末帧后循环至第一帧 |
| 手动切换 | 点击顶部分页 Tab 立即切换到对应帧，并重置该帧自动播放进度 |
| 视觉区 | 右侧展示与当前帧主题匹配的装饰视觉（不承载业务数据）；角标文案固定「可信 · 可溯 · 可计量」（可配置） |

#### 元素说明

| 元素 | 需求说明 |
|------|----------|
| 分区容器 | 无障碍名称「首屏焦点」。背景为装饰性网格/光晕，不参与业务逻辑。 |
| 价值主张 Tab | 三个 Tab，文案分别为「平台能力」「版权核验」「智能审核」。当前帧 Tab 高亮；高亮 Tab 上展示自动播放进度条（时长与自动间隔一致）。 |
| 主标题 | 当前帧的主标题文案（单行或换行展示）+ 强调句（渐变高亮样式）。字段：`title`、`highlight`。 |
| 导语 | 当前帧说明文案。字段：`lead`。超出自然折行。 |
| 能力概览指标 | 三项静态指标，用于强化信任（非实时统计）：① 数值「6」+ 标签「核心产品」；② 数值「API」+ 标签「开放接入」；③ 数值「权威」+ 标签「登记数据」。文案可配置，默认如上。 |
| 主题视觉 | 随当前帧 `id`（如 trust / verify / audit）切换装饰插画，纯展示。 |
| 视觉角标 | 叠于视觉区，文案见上。 |

#### 默认三帧内容结构（精简）

| 帧 id | Tab 文案 | 主标题结构 | 内容要点 |
|-------|----------|------------|----------|
| trust | 平台能力 | 可信数据能力 + 护航版权经营 | 面向内容平台与版权机构；核验、智能审核与开放 API |
| verify | 版权核验 | 版权核验 + 权威可溯 | 覆盖 DCI / 登记信息 / 证书三类核验 |
| audit | 智能审核 | 智能辅助审核 + 提效合规 | 覆盖安全审核 / 查重 / 疑似侵权 |

## 版权核验专题页

## 忘记密码页

> **C1 状态**：本章已按元素级补全。  
> **路径**：`/forgot-password`  
> **入口**：登录弹窗「忘记密码？」关闭弹窗后跳转本页  
> **流程**：4 步线性向导（邮箱 → 验证码 → 新密码 → 完成），不可跳步；可从步骤 2 返回步骤 1 改邮箱。

### 业务故事 / 目标

为企业用户在门户站内完成密码找回：验证绑定邮箱 → 校验验证码 → 设置新密码 → 完成提示，从而恢复登录能力。

### 内容来源与业务规则

| 需求点 | 说明 |
|--------|------|
| 适用对象 | 已开通且绑定有效邮箱的企业用户账号 |
| 数据范围 | 访客可访问本页；真正重置仅对「邮箱已绑定到有效账号」的请求生效 |
| 验证码 | 发至绑定邮箱；建议 4～6 位数字；有效期与重发间隔由后端约定（如有效 10 分钟、重发冷却 60 秒）；校验失败可重试 |
| 邮箱不存在 / 未绑定 | 产品策略二选一并全站统一：① 明确提示「该邮箱未绑定账号」；② 为防枚举仍提示「若邮箱已绑定将收到验证码」且不进入可区分路径。默认建议采用 ②，步骤 UI 仍可进入步骤 2，但未绑定邮箱收不到码 |
| 成功结果 | 账号密码更新为新密码；旧密码立即失效；不自动登录，引导回首页再用新密码走登录弹窗 |
| 与客户平台 | 门户与客户工作台共用同一账号体系时，重置后两侧登录均使用新密码 |

## 相关平台与依赖

| 依赖项 | 说明 |
|--------|------|
| 使用者 | 已开通或待入驻的**企业账号**（经门户登录后进入） |
| 上游 | 运营后台审核入驻、配置产品与额度；统一后端履约与计费（见总章闭环一、二） |
| 下游 / 联动 | 开放 API 调用方使用本平台创建的 API Key；额度与流水与运营统计一致 |
| 本平台职责 | 入驻申请、工作台与额度感知、六大产品 WebUI 调用、API Key、账号与合同、API 文档与帮助 |
| 不在本平台 | 门户营销与对外法律页；运营审核与内容配置；自助注册（无自助开户） |

关键闭环（简述）：门户登录 → 未开通则填入驻申请 → 运营通过并配额度 → 工作台进入产品 WebUI / 管理 Key / 查文档 → 每次成功调用扣次。

**访问门禁（全局）**：

| 状态 | 行为 |
|------|------|
| 未登录 | 应引导至门户登录（会话由统一身份签发） |
| 已登录且控制台未解锁（入驻未通过） | 仅可访问「入驻申请」；访问其它路由强制回到 `/apply` |
| 已登录且已解锁 | 可访问工作台及全部业务页；访问 `/apply` 可重定向至工作台 |

根路径 `/`：已解锁 → `/desk`；未解锁 → `/apply`。

## 全局：布局壳层与公共交互

> **C1 状态**：本章已按元素级补全。  
> **适用范围**：客户平台全部已登录页（含入驻锁定态）。  
> **布局**：左侧栏 + 右侧（顶栏 + 内容区）。

### 业务故事 / 目标

为企业用户提供统一的侧栏 + 顶栏工作区：侧栏承载产品导航，顶栏提供文档/帮助与账号入口；入驻未完成时收敛导航，避免误入未授权能力。

### 会话与解锁态

| 需求点 | 说明 |
|--------|------|
| 企业会话 | 与门户共用企业用户身份；客户平台需在会话有效时保持登录。会话失效或未登录访问业务路由 → 跳转门户登录入口（部署配置的门户 URL + 登录能力）。 |
| 解锁态 `unlocked` | 以服务端「入驻已通过且控制台已开通」为准（租户权益生效）。本地仅作展示缓存，以接口刷新结果为准。 |
| 锁定态 `locked` | `!unlocked`：侧栏/顶栏收敛；布局路由守卫将非 `/apply` 请求重定向到 `/apply`。 |
| 展示名规则 | **锁定**：展示登录账号（用户名）。**解锁**：优先展示企业全称；若无则回退登录账号或联系人姓名（全站统一一处规则）。 |
| 头像字 | 取展示名去空白后首字；空则「企」。 |

## 入驻申请页

> **C1 状态**：本章已按元素级补全。  
> **路径**：`/apply`  
> **门禁**：控制台未解锁时可访问；已解锁访问本页 → 重定向 `/desk`。  
> **状态机**：与总章「开通申请」一致：未提交 ↔ 审核中 ↔ 已驳回；已通过即解锁（本页不再停留）。

### 业务故事 / 目标

将线下签约企业的主体、联系人与合同材料提交给运营审核；审核通过前用户仅停留本页；驳回后可改资料再提；通过后解锁控制台。

### 内容来源与状态

| 需求点 | 说明 |
|--------|------|
| 数据来源 | 当前登录企业账号的入驻申请单；登录账号只读来自身份服务 |
| 访问状态 | `unsubmitted`（未提交，含撤回后）/ `pending`（审核中）/ `rejected`（已驳回）/ `approved`（已通过，不展示本页） |
| 可编辑 | 仅 `unsubmitted`、`rejected` |
| 只读 + 可撤回 | 仅 `pending` |
| 审核动作 | 通过/驳回在**运营后台**完成；通过后本账号解锁；驳回须带回原因供本页展示 |

#### 状态与界面对照

| accessStatus | 横幅 | 主区 | 主操作 |
|--------------|------|------|--------|
| unsubmitted（无草稿） | 开通引导 | 可编辑表单 | 提交入驻申请 |
| unsubmitted（有草稿/撤回后） | 待提交申请 | 可编辑表单（预填保留资料） | 提交入驻申请 |
| pending | 申请审核中 | 只读资料 | 撤回申请 |
| rejected | 申请未通过 | 可编辑表单（预填 + 可见原因） | 重新提交申请 |

### 板块：只读资料（审核中）

展示提交快照，字段与下表「可编辑表单」一致，只读。空值展示「—」。金额有值时：前缀「¥ 」+ 千分位整数（元）。附件只展示文件名，用顿号连接；无附件「—」。合作起止格式：`{开始} ~ {结束}`（yyyy-mm-dd）。

| 元素 | 需求说明 |
|------|----------|
| 企业信息区块 | 标签+值：统一社会信用代码、公司全称、法人代表、有效联系地址。 |
| 联系信息区块 | 联系人姓名、联系人电话、联系人邮箱。 |
| 合同信息区块 | 合同编号、合作起止、合同总金额、合同附件。 |
| 意向产品区块 | 已勾选产品标准名称，多个用顿号连接；未选展示「—」。 |
| 撤回申请 | 按钮原文「撤回申请」。点击打开撤回确认弹窗。 |

#### 撤回确认弹窗

| 元素 | 需求说明 |

## 修改密码页

> **C1 状态**：本章已按元素级补全。  
> **路径**：`/account/password`  
> **入口**：账号中心「修改密码」、顶栏用户菜单「修改密码」。

### 业务故事 / 目标

在已登录前提下分步改密：验证当前密码 → 绑定邮箱验证码 → 设置新密码 → 完成；成功后其他设备会话失效，当前会话保留。

### 内容来源与规则

| 需求点 | 说明 |
|--------|------|
| 绑定邮箱 | 取自租户联系邮箱；展示时脱敏（本地首字符 + `***@` + 域名） |
| 验证码 | 6 位数字；有效期 **10** 分钟；同一邮箱发送间隔 **60** 秒；每日上限 **10** 次 |
| 新密码强度 | 至少 8 位；大写/小写/数字/特殊符 `{!_@#}` 中至少满足 **3** 种 |
| 校验时机 | 各步点击主按钮时统一校验，页内一条错误原文 |
| 离开页 | 重置流程中间态（验证标记与未用验证码） |

---

### 板块：页头与引导

| 元素 | 需求说明 |
|------|----------|
| 标题 | 「修改密码」 |
| 返回 | 按钮「返回账号中心」→ `/account` |
| 引导原文 | 「为保障账号安全，修改密码需依次验证当前密码与绑定邮箱验证码。修改成功后将下线其他设备的登录会话，仅保留当前会话。」 |
